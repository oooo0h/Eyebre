# Eyebre 公司介绍主页

当前方向：在参考站原有框架上替换内容，保留原来的文字位置、字号层级、画幅、背景线条、3D 场景、鼠标涂抹、卡片视差、详情页缩放过渡与滚动叙事。不要重新设计页面。

已按后续反馈局部优化首屏：Logo 放大，标题压缩为两个语义短句并调整宽度、行距和留白；中文标点与前一个字绑定，避免行首标点。其他区块继续沿用原框架。

电脑端（宽度至少 1024px）进一步将 Logo、竖线与两行文案组成紧凑的固定品牌组：竖线由上至下显现后，两侧内容从竖线边界向外滑出，左右回弹一次并停止。`dist/desktop-intro.js` 使用本地 GSAP 时间轴实现，等待原场景预加载结束再播放。手机端保留原布局及入场方式；系统减少动态效果时显示静态品牌组。页面中的真实 H1 保留原位置、测量和语义，电脑端用独立视觉副本与 Logo 同步入场。

产品图册按确认顺序展示 10 类：双筒望远镜、天文望远镜、单筒望远镜、瞄准镜、观鸟镜、测距仪、夜视仪、热成像、显微镜、支架&夹具。中英文名称、副标题及相邻图册导航统一定义在 `dist/brand.js` 的 `catalogues` 数组中。

## 运行

在本目录执行 `node server.mjs`，预览地址为 `http://127.0.0.1:4186`。这是无需构建的静态站，发布目录为 `dist/`。`npm run check` 检查项目 JavaScript 语法。

## 文件

- `dist/index.html`：保留原始主页的结构和文字节点。
- `dist/_astro/about.CNa9RfUh.css`：参考站样式，保留原内容。
- `dist/_astro/hoisted.CUO_IjfL.js`：参考站动画引擎。仅适配资源源站、公司联系入口与品牌/导航桥接，不重写原效果。
- `dist/brand.js`：中英文文案、Eyebre 品牌、电话、Language 按钮与目录占位内容。
- `dist/brand.css`：Language 控件、品牌标识、首屏文字局部排版与中文分词兼容。
- `dist/desktop-intro.js`：仅电脑端的竖线、Logo 与标语入场编排，移动端不加载 GSAP。
- `dist/projects/*/index.html`：保留参考卡片到详情的过渡所需页面。详情页显示图册占位文案，视觉素材稍后替换。

首次访问默认英文；Language 支持简体中文，选择保存在浏览器中。切换语言会重新初始化原动画引擎并恢复滚动位置，避免破坏原有文字分行和动画缓存。
